## Deploy

로컬에서 수정한 뒤 아래 순서로 반영합니다.

```bash
git status -sb
git add .
git commit -m "Update portfolio"
git push origin main
```

`main` 브랜치에 push하면 GitHub Actions가 `index.html`, `about.html`, `portfolio.html`, `style.css`, `assets` 폴더를 GitHub Pages로 배포합니다.-->
