Java/Spring과 Python AI를 연결하는 하이브리드 개발자

제 가장 큰 강점은 연결입니다. 사람과 사람, 사람과 기술, 그리고 기술과 서비스를 연결하며 문제의 본질을 이해하고 해결하는 과정을 좋아합니다.

처음 개발에 관심을 갖게 된 계기는 단순했습니다. 컴퓨터 안에서 명령어 한 줄을 입력하면 동작이 바뀌고, 작성한 코드가 화면과 기능으로 바로 나타나는 과정이 흥미로웠습니다. 게임 제작 영상에서 코드와 명령어에 따라 화면이 바뀌는 모습을 보며, 기술이 눈에 보이는 결과로 이어지는 과정에 자연스럽게 끌렸습니다.

처음부터 개발자의 길이 명확했던 것은 아닙니다. 2020년 인공지능 교육 과정에 도전했고, 이후 머신러닝과 딥러닝을 접해보기도 했지만, 당시에는 기초가 부족해 기술의 구조를 제대로 이해하지 못했습니다. 그래서 한동안 미군 부대 근무와 소방설비 공부를 하며 제 적성을 다시 확인하는 시간을 보냈습니다.

마지막이라는 마음으로 다시 개발 교육에 지원했고, Java와 웹 개발을 배우면서 비로소 이 길이 저에게 맞는다는 확신을 얻었습니다. 이후 AI 심화 과정을 들으며 AI를 서비스 안에서 활용하는 방법에도 관심을 갖게 되었습니다. 단순히 화면에 데이터를 보여주는 것을 넘어, 사용자의 질문을 이해하고 관련 정보를 찾아 답변하는 흐름이 서비스 안에 들어갈 수 있다는 점이 매력적으로 느껴졌습니다.

짧은 기간 동안 AI를 깊게 이해했다고 말하기는 어렵습니다. 하지만 직접 AI 검색 기능을 구현하며 모델 성능뿐 아니라 데이터 구조, 검색 방식, API 연동, 응답 품질까지 함께 고려해야 실제 서비스가 된다는 것을 배웠습니다. 이 경험을 통해 AI를 단순 기능이 아니라 서비스의 문제 해결력을 확장하는 도구로 바라보게 되었습니다.

이 경험을 바탕으로 저는 특정 분야에만 한정된 개발자가 아니라, 웹 서비스와 AI 기술을 연결하고 필요하다면 반도체, 전자, 제조 등 다양한 산업의 문제를 소프트웨어로 해결하는 개발자로 성장하고자 합니다.

프로젝트 문제 해결 경험

PlusHome 가구 쇼핑 및 인테리어 상담 플랫폼 개발
PlusHome 프로젝트는 React, Spring Boot, MyBatis, OracleDB 기반으로 제작되었습니다. 사용자는 가구를 구매하고 인테리어 업체와 상담을 진행할 수 있으며 사업자는 상품과 상담을 관리할 수 있도록 개발했습니다. 저는 메인 화면, 통합 검색, 상품 문의, 추천/숨김, 대본 기반 챗봇 기능을 담당했습니다.

초기에는 검색어, 필터, 페이지 정보를 화면 상태로만 관리했기 때문에 새로고침이나 뒤로가기를 하면 사용자가 설정한 조건이 초기화되는 문제가 있었습니다. 이를 해결하기 위해 검색어, 필터, 페이지 정보를 URL QueryString으로 관리하는 구조로 변경해 새로고침과 URL 공유, 뒤로가기 이후에도 동일한 검색 결과를 유지할 수 있도록 개선했습니다.

추천 상품 숨김 기능도 화면에서만 상태를 관리했기 때문에 새로고침하거나 다시 로그인하면 숨김 정보가 초기화되었습니다. 사용자 ID를 기준으로 숨김 상품 정보를 데이터베이스에 저장하고, 로그인 시 사용자별 숨김 목록을 다시 조회하는 구조로 변경해 추천/숨김 상태가 지속적으로 유지되도록 개선했습니다.

RAG 기반 AI 가구 추천 챗봇
PlusHome에서 AI 추천 기능을 구현하지 못한 아쉬움이 남아 개인 프로젝트로 CNN 기반 이미지 분류와 RAG를 결합한 가구 추천 챗봇을 구현했습니다. Streamlit을 활용해 이미지 업로드부터 추천 결과까지 확인할 수 있는 프로토타입도 함께 제작했습니다.

MobileNetV2 기반 전이학습 모델을 적용하는 과정에서 TensorFlow/Keras 버전 차이로 모델이 정상적으로 로드되지 않는 문제가 발생했고, 호환 가능한 모델을 별도로 생성해 Streamlit 환경에서 사용할 수 있도록 개선했습니다. 또한 로컬 Ollama 운영의 메모리 제약과 API 연결 문제를 확인한 뒤 Gemini API 기반으로 구조를 변경해 이미지 분류, RAG 검색, AI 답변 생성까지 전체 파이프라인을 완성했습니다.

BidMatch AI 기반 나라장터 입찰 공고 추천 서비스 개발
BidMatch 프로젝트는 React, Spring Boot, FastAPI, PostgreSQL(pgvector), Redis 기반으로 구축한 AI 기반 나라장터 입찰 공고 추천 서비스입니다. 자연어 기반 공고 검색 및 탐색, AI 추천/요약, 입찰 자격 자가진단, OCR, RAG 챗봇 기능을 제공하며 Docker와 Jenkins 기반 CI/CD 환경에서 개발했습니다.

가장 많은 고민이 필요했던 부분은 자연어 기반 AI 검색 품질 개선이었습니다. 검색어에서 지역, 키워드, 예산 조건을 추출해 검색 조건으로 구조화하고, 자모 분해와 유사도 비교를 활용한 지역명 오타 보정을 적용했습니다. 이후 BGE-M3 임베딩으로 의미적으로 유사한 후보 공고를 검색한 뒤 Hybrid 검색을 통한 재정렬을 적용해 검색 조건과 의미 유사도를 함께 반영하도록 개선했습니다.

추천 이유, 조건 일치 여부, 추가 확인이 필요한 요소를 함께 제공해 사용자가 검색 결과를 쉽게 판단할 수 있도록 했으며, AI 응답 실패 시에는 일반 검색으로 전환되는 fallback 로직을 구현해 서비스의 안정성을 높였습니다.
