PlusHome

PlusHome은 가구 쇼핑과 인테리어 상담을 하나의 플랫폼에서 제공하는 6인 팀 프로젝트입니다. 저는 팀장으로 참여하며 메인 화면 일부, 통합 검색, 조건 기반 검색/필터, 상품 문의, 추천 및 숨김, 챗봇 검색 연계를 담당했습니다.

2026.04.27 ~ 2026.06.15 Team Leader React · Spring Boot · MyBatis · Oracle DB

사용자의 검색, 문의, 개인화 선택을 하나의 서비스 흐름으로 구현

통합 검색에서는 사용자가 키워드를 입력하면 관련 가구 상품과 인테리어 콘텐츠가 함께 조회되도록 구현했습니다. 조건 기반 검색/필터에서는 지역, 주거 유형, 면적, 예산 등의 선택 조건을 URL QueryString과 API 요청으로 전달하고, 새로고침 후에도 조건이 유지되도록 처리했습니다.

상품 문의 기능에서는 문의 작성, 목록 조회, 상세 확인, 이미지 첨부, 비밀글 여부, 답변 상태 표시를 구현했습니다. 이미지 첨부는 FormData 기반 multipart 전송을 활용했고, 문의 데이터가 서버와 DB에 저장된 뒤 화면에 다시 반영되는 구조를 확인하며 구현했습니다.

추천 및 숨김 기능은 사용자의 선택이 재접속 후에도 유지되어야 한다고 판단해 브라우저 로컬 저장이 아니라 DB에 저장되도록 구현했습니다. 이를 통해 개인화 기능에서는 화면 상태뿐 아니라 저장 데이터의 기준을 일관되게 관리하는 것이 중요하다는 점을 배웠습니다.
